Guildhall portable mode

While this file sits next to guildhall.exe, Guildhall keeps its settings, its
download cache and its record of installed apps in the GuildhallData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move Guildhall with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Guildhall) instead.
If GuildhallData can't be written (for example on a read-only drive), Guildhall says
so and uses %APPDATA%\Guildhall instead.
